# 🚀 E-Commerce Delivery Time Prediction

This project predicts delivery time using Machine Learning models.

## 📌 Features
- Distance
- Number of Packages
- Traffic Level
- Weather Conditions
- Delivery Type

## 🤖 Models Used
- Linear Regression
- Random Forest

## 📊 Evaluation Metrics
- MAE
- RMSE
- R² Score

## 📈 Visualization
- Actual vs Predicted graphs using Matplotlib

## 🛠️ Technologies
- Python
- Pandas
- Scikit-learn
- Matplotlib
